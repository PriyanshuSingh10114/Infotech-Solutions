# Project Overview

This project is a responsive compliance-focused landing page built using pure HTML5, CSS3, and JavaScript.

The objective of the assignment was to:
- Convert the provided Figma design into code
- Achieve pixel-perfect accuracy
- Ensure full responsiveness across devices
- Maintain clean and readable frontend architecture

The website includes:
- Responsive Navbar
- Mobile Sidebar Navigation
- Hero Section
- Informational Compliance Section
- Feature Cards
- Responsive CTA Buttons
- Vector Decorations & Assets
